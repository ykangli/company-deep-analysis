# 交付前人工质量门（Human quality gate）

`verify_report.py` 过了之后，**人工再走一遍这张表**。脚本只能查结构，查不出"数字对但结论错"。

逐项打勾。任何一项打不了勾，**不要交付**。

---

## A. 数据可信度（最高优先级）

- [ ] 报告里每个"承重数字"（零章三个数字、十二章结论、评分表依据、第九章各题答案）都能说出**具体来源文件名或接口名**
- [ ] 所有来自 subagent / 媒体 / 搜索摘要的承重结论，我都**回到一手文件反查过一次**
- [ ] 我用 `--grep` 或手工检索确认过：报告里点名的**公司名、产品名、交易名**确实出现在一手文件中
- [ ] 存在"报表净利含大额非经营性收益"的情况时，已给出**核心口径**并在显著位置警示
- [ ] 每处 `【推算】` 都有公式；每处 `【未能核实】` 都写了检索范围
- [ ] "已剔除/已纠正的数据"清单已写，且**包括我自己纠正过的推断**（不是只列别人的错）
- [ ] 数字一致性校验（E6）通过率 100%（或已逐条说明差异）

## B. 格式一致性（对照 assets/example-report-google-20261008.md）

- [ ] 文件头三行 blockquote（报告日期 / 数据来源 / 分析框架）齐全
- [ ] 十二章齐全，编号与范例一致（A股/港股无第八章）
- [ ] 每个表格的表头分隔行格式与范例一致（`|:---:|` / `|---:|`）
- [ ] 金额单位全篇统一并在表头注明
- [ ] 关键观察用有序列表，每条以**加粗短句**开头
- [ ] ⚠️ 只用于口径陷阱，未滥用
- [ ] 章节之间用 `---` 分隔
- [ ] 全文无"我认为/我觉得"，改用"本报告判断"
- [ ] 结尾有斜体免责声明

## C. 内容完整性（逐章自问）

- [ ] 零章：评分表 + 一句话结论（同时回答"公司好不好"和"价格贵不贵"）+ 三个数字（**不含市值/股价**）
- [ ] 一章：三句话解释 + 分部收入表 + 股权结构
- [ ] 二章：五年 + 最新中期；含 **2.6 盈利质量**一节
- [ ] 三章：含 **反向 DCF**；核心 PE 与 GAAP PE 并列
- [ ] 四章：每一段涨跌都归因为"基本面 / 情绪（周期）"
- [ ] 五章：明确回答"公司在回馈股东还是向股东要钱"
- [ ] 六章：每位移仓者都有**持仓时间 + 成本（或明确未能核实）**；章末有分歧总结
- [ ] 七章：每条事件带日期；**7.5 高管访谈表含 CEO 与 CFO 的原话**
- [ ] 八章（美股）：含"未能核实"的诚实说明 + "对投资者的含义"
- [ ] 九章：16 题全答，每题有标记与评级
- [ ] 十章：三条风险按发生率排序；情景概率合计 100%；有概率加权回报
- [ ] 十一章：**价格安全边际与综合分与零章一致**
- [ ] 十二章：**价格纪律表** + 仓位上限 + 跟踪变量 + 触发重估的信号

## D. 反常识自检（最容易翻车的地方）

- [ ] 我没有把"市值"或"股价"当作三个必记数字之一
- [ ] 我没有用 GAAP PE 作为估值锚（或在用的同时明确标注了失真幅度）
- [ ] 我没有把子公司的独立申报当成母公司的持仓变动
- [ ] 我没有把 A 类与 C 类股数相加算持股比例
- [ ] 我没有把 13F 的季末市值当成成本
- [ ] 我没有把"赠与"写成"减持"，也没有把"股权激励授予"写成"内部人增持"
- [ ] 我没有把传闻（如"某公司拟采购"）写成已签署合同
- [ ] 我没有用插值/估算填补缺失财年，而是写了"未能核实"
- [ ] 反向 DCF 的隐含假设与我的结论**逻辑一致**（不能一边说"很贵"一边写一个很低的隐含 FCF）

## E. 诚实性（这一节决定报告是否值得信任）

- [ ] 报告里至少有一句**明确不利于自己结论**的话
- [ ] "未能核实清单"不是空的，且不是敷衍
- [ ] 如果某项 `未能核实` 恰好是结论的关键变量，我**明确写出了这一依赖**
- [ ] 我没有用"由于篇幅/时间原因"跳过任何一章或一题
- [ ] 我没有给出买入/卖出指令，只给了估值区间与价格纪律

## F. 时效性

- [ ] 数据截止日已注明；行情注明收盘/盘中
- [ ] 已提示最近一期财报的披露日与下一期的大致时间
- [ ] 有"所有前瞻预测以公司正式披露为准"的声明

---

## 签字式收尾（写在报告的时效性说明里）

```
数据截止：YYYY-MM-DD
已核实的最高来源级别：L1（SEC 8-K / 10-Q / 10-K）
未能核实项：N 项（见清单）
已纠正项：M 项（见清单）
校验：verify_report.py 通过（0 error）
```

---

**最后一问**：如果三年后有人拿这份报告复盘，他能不能看出**当时的哪些判断是基于核实的事实、哪些是基于推算、哪些是当时就没查到**？

如果看不出，说明标注不够，回去补。
