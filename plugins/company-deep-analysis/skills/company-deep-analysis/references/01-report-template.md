# 报告模板（严格套用）

> 本文件是输出契约。`assets/example-report-google-20261008.md` 是已填好的范例——**格式有疑问时以范例为准**，本模板给出骨架与每个表格的必备列。
>
> 写作规则：
> 1. 所有金额表统一标明单位（如"十亿美元"），同一张表内不混用单位。
> 2. 所有"事实"都必须带证据标记（`【已核实】`/`【推算】`/`【未能核实】`）或紧邻的数据来源说明；正文叙述可依赖本章数据来源块统一覆盖，但**任何被当作结论使用的数字必须能追溯到本章来源**。
> 3. 表格用 `|:---:|` 居中、`|:---|` 左对齐；金额右对齐用 `|---:|`。与范例保持一致。
> 4. 每个"关键观察"清单用有序列表，每条以**加粗短句**开头，然后展开。
> 5. ⚠️ 标记用于提示口径陷阱或失真数据；✅/❌/⏳ 用于验证状态。

---

## 文件头（固定格式）

```markdown
# {公司中文名}{若有英文名}（{代码}）深度分析报告

> **报告日期：{YYYY-MM-DD}**
> **数据来源**：{逐项列出，含具体接口/文件/披露日}：{例如} 公司 SEC 8-K 财报新闻稿（{期间}，[SEC EDGAR](...)）、{期间} 年报/半年报、{行情接口}（{截止时间}）、{内部人交易来源}、{持仓披露来源}
> **分析框架：以 `{checklist 路径}` 的 16 个核心问题为基础**
> **免责声明：本报告仅为基本面研究，不构成任何投资建议。所有预测数据均需以公司正式披露为准。**
```

---

## 零、核心结论摘要（一页纸）

必备三块：

**（1）评分表**——维度固定，分数 0-10：

```markdown
| 维度 | 结论 | 评分 |
|------|------|:----:|
| 商业模式与护城河 | ... | x/10 |
| 财务健康度 | ... | x/10 |
| 盈利质量 | ... | x/10 |
| 管理层与资本配置 | ... | x/10 |
| 当前估值（{日期}，{价格}） | ... | x/10 |
| **价格安全边际** | ... | x/10 |
| **综合评分** | ... | **x/10** |
```

**（2）一句话结论**——必须同时包含"公司好不好"和"价格贵不贵"两个判断，不允许只答一个。

**（3）最重要的三个数字**——必须是本报告计算出来的、且读者最该记住的三个（通常是：真实估值倍数、最关键的现金流或盈利指标、最关键的外部验证信号）。**不允许把"市值"或"股价"作为其中之一。**

---

## 一、公司速览：它是做什么的？

1. **公司全称、代码、上市地、上市时间、注册地**一段话。
2. **分部收入表**（必备列）：

```markdown
| 分部 | {最新期} 收入 | 占比 | 主要内容 | {最新期} 经营利润 |
|------|:---------:|:----:|---------|:-------------:|
```

3. **"用三句话向一个 10 岁孩子解释它怎么赚钱"**——三条编号，每条带一个具体数字。这是 checklist 第 1 题的正文。
4. **股权结构**——股本类别、票数、总股本、创始人/控股股东控制权比例、员工人数。

---

## 二、核心财务数据（近五年 + 最新中期）

### 2.1 营收、利润与盈利能力

必备列：**年份 / 营业收入 / 同比 / 营业利润 / 营业利润率 / 净利润 / 同比 / 净利率 / 毛利率 / EPS**。
表后写"关键观察"，3–5 条，必须点出：增速拐点、利润率方向、唯一负增长年份及其原因。

### 2.2 净资产收益率（ROE）

表：ROE、ROA、资产负债率（各年 + 多年平均）。
必须给出结论：ROE 是否依赖杠杆（拆解为利润率 × 周转率 × 权益乘数，或至少说明负债结构是否无息）。
⚠️ 若最近一期净资产因一次性项目/增发而剧变，必须提示 ROE 的"含金量"变化。

### 2.3 年复合增长率（CAGR）

表：营收 / 营业利润 / 净利润 / EPS / 经营现金流 / **自由现金流**，分别给 3 年、5 年（如有 6 年再加一列）。
必须点出：**若 FCF 的 CAGR 显著低于净利润 CAGR，说明资本开支正在吞噬利润**——这是判断"重资产化"的核心信号。

### 2.4 分业务收入结构演进

表：各分部近 2–3 年收入 + 最新单季同比。
必须回答：新业务占比是否在提升、增长最快的业务占比多少（避免把小业务的爆发当成全公司增速）。

### 2.5 现金流与自由现金流

必备列：**经营现金流 / 资本开支 / 自由现金流 / FCF 率 / FCF 与净利之比 /（如有）折旧摊销**。
必须给出：最新年度、TTM、最新中期、最新单季四个口径；**若最近一期 FCF 为负，必须显著标记并说明原因与后续指引**。

### 2.6 盈利质量：核心利润 vs 报表利润 ★本章不可省略

当净利润包含大额投资浮盈、公允价值变动、资产处置、诉讼赔付等非经营性项目时：

```markdown
| 期间 | 报表净利 | 一次性/投资损益（税前） | 税后影响 | **核心净利** | **核心EPS** | 报表EPS |
|------|:-------:|:--------------------:|:-------:|:----------:|:----------:|:------:|
```

并说明：①公司是否自己披露了这一影响（披露的引用原文）；②该项目的性质（是否产生现金流）；③若该项目对应的资产价格反向变动会怎样。
**若公司不存在此类项目，写明"无重大非经常性项目"并给出扣非净利与报表净利的比值。**

### 2.7 资产负债表与财务安全

必备列：总资产 / 总负债 / 股东权益 / 现金及等价物 / 有价证券 / **有息负债** / 商誉 / 固定资产 / 资产负债率 / 每股净资产。
必须回答 checklist 第 8 题：**"如果明天信用市场冻结，它靠自己的现金流能撑多久"**——用现金+证券 ÷ 年经营现金流给出年数。

---

## 三、估值分析

### 3.1 当前估值水平

必备行：股价（含时间）、总股本、总市值、**静态PE**、**PE(TTM)**、**核心PE**、核心静态PE、PS、PB、EV/营业利润、**FCF收益率**、**股息率**、股东总回报率。
⚠️ 若 PE(TTM) 与核心 PE 差异 >30%，必须写出失真警告。

### 3.2 近五年估值区间：当前处于什么位置

两个子表：①用当年实际 EPS 计算的**年度静态 PE 区间**；②**TTM PE 时序**（按报告期后首个交易日）。
结论必须明确说"当前处于近五年区间的上沿/中部/下沿"，并与至少一种口径的历史区间对比。

### 3.3 同业估值对比

表：可比公司 / 股价 / 市值 / 静态PE / PE(TTM) / PB，并给出相对贵贱的判断（说明本公司在哪一维度便宜、哪一维度贵）。

### 3.4 内在价值测算（至少三种方法交叉验证）

- **方法一：盈利 × 合理 PE**——给悲观/保守/中性/乐观四档，每档写清 EPS 假设与 PE 依据。
- **方法二：DCF**——必须写清 WACC、永续增长率、起始 FCF 口径；若当期 FCF 为负，说明从哪一年起算并解释资本开支正常化假设。
- **方法三：反向 DCF**——**用现价倒推市场隐含的稳态自由现金流**，再评估该假设是否合理。这是最能揭示"价格里已经包含了什么"的一步，**不可省略**。
- 如有行业专用指标（如回收率 = 分部经营利润 ÷ 资本开支），作为方法四加入敏感度刻度。

### 3.5 卖方分析师共识

表：平均目标价（注明数据商与家数）/ 区间 / 评级分布 / 街高 / 街低 / 最近上调或下调的点名机构与理由（按日期）。
必须点出：**上调理由集中在哪个业务上**——这往往揭示当前估值最新、最未经验证的那一块。

---

## 四、股价走势分析

1. **4.1 长期收益**：表——自 1/2/3/5/6 年前至今日的累计与年化（**复权含股息**）；含最近一个完整年度涨幅。
2. **4.2 月度收盘价**表（近 2 年）。
3. **4.3 关键点位与事件**表：日期 / 价格 / 事件。至少覆盖近 12 个月。
4. **4.4 最近一个月逐日**表：日期 / 开 / 高 / 低 / 收 / 成交量。
5. **4.5 波动归因**：分上涨段与下跌段，逐条给驱动因素，并**判定每一段是"基本面驱动"还是"情绪/周期驱动"**。这是 checklist 第 10 题的正文。
6. **4.6 波动特征**：单日最大跌幅、区间最大回撤、52 周区间与振幅、对持仓者的含义。

---

## 五、分红与回购

1. **5.1 股息**：逐次派息表（除息日 / 每股 / 备注）；年度每股与总额、占净利比例、当前股息率；提价历史。
2. **5.2 回购**：逐年回购金额 / 同比 / 稀释股本 / 当年净利。
   **必须回答**：回购是否在减少股本（若回购但股本增加，说明被股权激励或增发抵消）；最近一期回购是否停止。
3. **5.3 股东总回报与融资结构**：表——逐年"回购 + 股息合计"与"净发债 / 净增发"。
   **必须给出判断**：公司当前是"回馈股东"还是"向股东要钱"。

---

## 六、股东结构、名人持仓与内部人交易

章首必须放**口径警示**（多类股不可相加；13F 是季末市值非成本；期权按名义价值）。

1. **6.1 各主要股东/名人持仓**——每人一张表，必备列：

```markdown
| 报告期 | 披露日 | {类别A}股数 | {类别C}股数 | 合计股数 | 期末市值 | 占其组合 | 排名 |
```

以及**持仓时间与成本**表：

```markdown
| 买入批次 | 股数 | 价格锚点（注明来源） | 估算成本 |
```

必须给出：首次买入时点、加权平均估算成本、当前浮盈状态、**现价与其成本的关系**（折价/溢价多少）。
若成本无法核实的，写"未能核实"并说明 13F 不披露成本。

2. **6.2–6.n** 其余知名投资者汇总表（标的 / 本期操作 / 规模 / 备注），严格区分 A/C 类。
3. **6.(n+1) 公司内部人交易**——表：姓名职务 / 日期 / 股数 / 价格 / 金额 / 交易后持股。
   必须回答：**本期是否有内部人公开市场买入**（若无，明写"无"）；创始人行为是"赠与"还是"卖出"（二者不可混为一谈）。
4. **6.(n+2) 机构持股**——机构家数、前几大机构及其占比（无法核实的写"未能核实"）。

章末必须有**分歧总结**：同一季度里谁在买、谁在卖，并指出"名人持仓不能作为买入理由"。

---

## 七、近期大事件

分五节，每条必须带**日期**：

- **7.1 监管与合规**（诉讼、反垄断、罚款、政策），并给出对商业模式的实际影响判断。
- **7.2 产品与技术**（新产品、技术里程碑、客户合同）。
- **7.3 资本运作**（融资、发债、并购、分拆、战略投资），带金额。
- **7.4 关键高管变动**（任职、离职、职位调整），并判断是正向还是风险信号。
- **7.5 高管访谈要点**——**表格：人物 / 场合与日期 / 关键表态（引号原文）**。
  这是 checklist 中"管理层坦诚"与"未来展望"的关键证据。**至少包含 CEO 与 CFO 在最近一次业绩会的表态**，以及最近一次深度访谈。

## 八、白宫官员投资情况（仅美股；A股/港股删除本章）

章首必须写明："本节结论建立在系统检索之上，严格区分【已核实】与【未能核实】。"

- **8.1 总统/最高层本人**的财务披露与交易（含披露日、页数、方向、金额级差），若涉及本公司必须明确写出。
- **8.2 内阁与高级官员**表：官员 / 已核实的利益冲突 / 是否涉及本公司。
- **8.3 与本公司直接相关的"政治-资本"接口**（顾问委员会任职、政策立场、监管互动）。
- **8.4 本节结论**：明确写出"已核实什么"与"未能核实什么"，并给出对投资者的含义（通常结论是：**官员个人账户不构成投资逻辑，真正有意义的变量是监管环境**）。

⚠️ 若检索不到任何官员持有本公司股票的证据，**必须如实写"未能核实到任何一条"，不得用"可能持有"等模糊表述填充**。

## 九、买入检查清单 —— 16 个核心问题逐条作答

格式（每个问题一个区块）：

```markdown
**[✓ 或 △ 或 ✗ 或 ⚠️] {N}. {问题原文}**

**答案：**{一句话结论}

{表格或论据}

> **评级：{通过/基本通过/不通过}（x/10）。**{一句限定语}
```

标记含义：`✓` 通过、`△` 有条件通过、`✗` 不通过、`⚠️` 行为控制类需自省。

详见 `references/02-checklist-mapping.md`：每个问题需要哪些证据、什么样的答案算合格。

**16 个问题必须全部作答，一个都不能少。** 不得把多个问题合并成一个回答。

## 十、公司未来发展分析

1. **10.1 增长驱动力**——编号列出，每条给出量化依据（收入/订单/客户数），并标注"已兑现/未验证"。
2. **10.2 主要风险**——表：排序 / 风险 / 说明 / 可能性 / 杀伤力。**最可能发生的排前面，最致命的单独标注。**
3. **10.3 三种情景预测**——表：指标 / 悲观 / 中性 / 乐观，含概率、核心假设、逐年营收与 EPS、资本开支、稳态 FCF、合理 PE 区间、目标股价、**年化回报**；表后给出**概率加权预期年化回报**并与历史回报对比。
4. **10.4 未来 6 个月关键观察窗口**——表：时间 / 事件 / 关注点 / 影响方向。最后一列用"正向/偏负/双向"。

---

## 十一、投资安全边际总结

固定维度评分表（与第零章呼应但不重复）：商业模式与护城河 / 财务健康度 / 盈利质量 / 成长性 / 管理层质量 / 资本配置 / 估值水平 / **价格安全边际** / 行业周期位置 / **综合安全边际**。
每个维度给一句评估 + 分数。**"价格安全边际"与"综合"两行必须与第零章一致。**

---

## 十二、最终结论与操作建议

1. **12.1 结论**——分"正面（必须承认的事实）"与"负面（同样必须承认的事实）"两个编号列表，各 5–7 条。
2. **12.2 价格纪律**——必备表：

```markdown
| 价格区间 | 对应 {估值口径} | 判断 | 建议动作 |
|---------|:-------------:|------|---------|
| > $X | > xx倍 | 明显高估 | 减持/不买 |
| $A-$B | ... | 公道价格（当前区间） | 可分批建仓 |
| $C-$D | ... | 明显低估 | 重点加仓 |
```

并给出：仓位建议（含上限）、分批方案、**必须跟踪的 4 个变量**、以及**触发重新评估（而非机械补仓）的信号**。

3. **12.3 一段话总结**——用一段话同时讲清"公司有多好"和"价格有多贵"，允许引用名人持仓的分歧来收束。

---

## 数据来源与时效性说明（固定收尾）

- **行情**：接口名、截止时间、当日是否盘中。
- **财务**：逐份列出一手文件（含披露日与原文链接）、历史序列来源接口。
- **其他**：股东、内部人、持仓、官员、分析师共识各自来源。
- **未使用/已剔除的数据**：编号列出被弃用的传闻、口径错误的数字、以及**你曾经写成事实后又纠正的推断**（诚实记录，供后续复查）。
- **关于本报告的证据分级**：重申三档标记的含义。
- **时效性**：数据截止日；下一份财报日期；所有前瞻预测以公司披露为准。
- 末尾斜体免责声明。

## 排版细则

- 数字千分位用逗号；金额统一"亿美元/十亿美元/亿元"并全篇一致。
- 同比用 `+12.3%`，负值用 `-21.1%`。
- 表格内"未能核实"直接写中文，不要留空。
- 加粗只用于：结论、关键数字、警示。
- ⚠️ 只用于口径陷阱；不要用于普通强调。
- 每章之间用 `---` 分隔。
- 全篇不出现"我认为/我觉得"；用"本报告判断/本报告的结论是"。
- 章节标题层级：`## 一、` 中文数字 + 顿号；子节 `### 2.1 `；再下一级用加粗行内标题。
