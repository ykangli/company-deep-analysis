# 持仓、内部人与官员投资核查方法

三件事合在一份文件：**名人持仓**（含持仓时间与成本）、**公司高管自己的投资/交易**、**白宫官员投资**（仅美股）。

先立三条口径铁律：

1. **多类股分列，永不相加。** A 类与 C 类（或 H 股与 A 股）经济权利可能相同但投票权不同，申报主体分开报。**绝不用某一类股数 ÷ 总股本算持股比例。**
2. **申报的是季末市值，不是成本。** 报告里的"投入 X 亿"必须区分是"季末市值"还是"实际成本"。
3. **披露日市价 ≠ 季末价。** 同一持仓常出现差 15% 的两个"市值"，口径不同，二者都"对"。

---

## 第一部分：名人持仓核查

### 1.1 必须回答的六个问题

对每一位被点名的投资者（巴菲特、李录、段永平，以及任何用户指定的名字），**必须**给出：

| 字段 | 说明 | 若无法获得 |
|------|------|-----------|
| **首次买入时点** | 哪一年哪一季度，哪个申报期首次出现 | `未能核实` |
| **逐季持仓** | 报告期 / 披露日 / 各类股数 / 期末市值 / 占其组合 / 排名 | 缺项写 `未能核实` |
| **持仓时间** | 已持有多少个季度/年 | — |
| **成本** | 见 1.3 的成本推算方法 | `未能核实` + 说明 13F 不披露成本 |
| **当前盈亏状态** | 现价 vs 成本锚，折价/溢价百分比 | — |
| **公开表态** | 该投资者对这家公司的**原话**与日期 | 无表态就写"未见公开表态（未能核实）" |

### 1.2 数据来源与陷阱

- **13F-HR**：季度结束后 45 天内提交。覆盖需申报的美股多头（含期权），**不含**空头、非美上市股票、债券、现金。
- **Form 4**：内部人交易，交易后 2 个交易日内提交。**看到 Form 4 才算成交；Form 144 只是"拟卖出意向通知"。**
- **A股**：十大流通股东（季报/年报）、股东户数、龙虎榜。
- **港股**：HKEX 权益披露（持股 ≥5% 须申报）、CCASS 持股。

⚠️ **一号陷阱：申报主体搞错。** 集团旗下子公司常单独申报 13F。**"某某卖出 X 公司"的头条，很可能是子公司的独立申报，而不是母公司持仓变动。** 必须先确认申报主体（CIK），再下结论。真实案例：某头条称"巴菲特卖出 Alphabet"，实为其子公司 New England Asset Management 的独立 13F，而母公司同期在大幅增持。

⚠️ **二号陷阱：把公司回购或定向增发当成内部人买入。** 公司回购是公司层面行为；向外部投资者私募发行新股是**公司向投资者融资**，不是内部人增持。两者都不构成"内部人看好"的信号。

### 1.3 成本推算方法（唯一可接受的做法）

13F 不披露成本。**按以下优先级推算，并标注 `【推算】`：**

1. **已披露的实际成交价**（最高优先级）——如定向私募的发行价、Form 4 中的成交价。这是硬数据。
2. **季度末收盘价**——用于"该季度新增股份"的近似成本；须注明用的是季末价而非均價。
3. **季度收盘均价**——比季末价更接近实际买入成本（若季度内均匀买入），须写出区间与均价。

**推算模板：**

```markdown
| 买入批次 | 股数 | 价格锚点（注明来源） | 估算成本 |
|---------|:----:|-------------------|:-------:|
| 20XX QX 建仓 | X 万股 | QX 季末 $A（**收盘均价 $B**，区间 $C-$D） | 约 E 亿 |
| 20XX-XX 私募配售 | X 万股 | **实际发行价 $F（已核实）** | F × 股数 |
| … | | | |
| **合计** | **X 万股** | — | **约 G 亿，摊薄均价约 $H** |
```

**强制要求**：表后必须写一句"**累计成本的区间估计为 X–Y，摊薄均价 Z，媒体流传的若干口径（列出）不一致，本报告采用推算口径**"。不得只给一个数字而不说来源。

**最有说服力的比对**：把现价与该投资者的**实际成交价锚点**直接相比，得出"跟随买入是否有折价"的结论。这是 checklist 第 12 题（安全边际）的核心证据。

### 1.4 分歧总结（章末必写）

同一季度内，往往有人在大买、有人在大卖。章末必须给出：

- 本期**买入方**名单与规模
- 本期**卖出方**名单与规模
- 明确结论：**"名人持仓不能作为买入理由——同一季度里最聪明的钱在同时大举买入和大举卖出。"**
- 并对比不同投资者的**仓位比例**（12% 与 3.6% 是两种完全不同的态度）

## 第二部分：公司高管自己的投资情况（必做）

### 2.1 应当收集的内容

| 项目 | 美股 | A股 | 港股 |
|------|-----|-----|-----|
| 交易明细 | Form 4（`ownership.xml`） | 董监高持股变动公告 | HKEX Director's Interests |
| 拟减持意向 | Form 144 | 减持计划预披露 | 权益披露 |
| 计划性交易 | 10b5-1 计划（10-Q/10-K 的 Insider Trading Arrangements 表） | 减持计划 | — |
| 薪酬与激励 | DEF 14A 薪酬汇总表 | 年报"董监高报酬" | 年报"董事酬金" |

### 2.2 必答的四个问题

1. **本期是否有内部人公开市场买入？** 若无，**明确写"无"**——这是重要信息，不能省略。
2. **卖出是计划性（10b5-1）还是自主决定？** 计划性减持不应过度解读。
3. **创始人/实控人的行为是"赠与"还是"卖出"？** 二者性质完全不同：赠与不产生现金所得，且通常进入慈善信托。**不要混为一谈。**
4. **薪酬激励与什么指标挂钩？** 与营收规模挂钩（易导致盲目扩张）还是与 ROE/每股 FCF/股价挂钩，是 checklist 第 7 题的关键证据。

### 2.3 表格模板

```markdown
| 姓名 / 职务 | 日期 | 类型 | 股数 | 价格 | 金额 | 交易后持股 | 10b5-1 |
|------------|------|:----:|:----:|:----:|:----:|:---------:|:------:|
```

另设一张"**仅权益增加（$0.00/股）**"表——这些是股权激励发放，**不是买入**，必须与买入严格分开。

### 2.4 陷阱

- **存托凭证（BDR/CEDEAR）页面的股数会严重失真**（同一笔交易可能被显示为 2,725 股而原始 Form 4 为 32,500 股）。**一律采用 Form 4 原始股数。**
- 高管日常卖出多为 RSU 归属后代扣税，**属于常规机制而非看空信号**，应归类说明。
- 计算"管理层持股占市值比例"时，**必须用占比而非股数**——0.02% 与 15% 是完全不同的公司。

## 第三部分：白宫官员投资情况（仅美股，必做）

> **适用性**：仅当标的是**在美国上市的公司**时撰写本章。A股、港股标的**删除本章**。

### 3.1 章首声明（固定）

必须写明："本节结论建立在系统检索之上，严格区分【已核实】与【未能核实】。本节检索的最大发现往往是'多数说法无法核实'。"

### 3.2 检索范围（逐项覆盖，写进报告）

| 对象 | 检索什么 |
|------|---------|
| **总统/最高层本人** | OGE 年度财务披露（提交日、页数、是否迟交）、期间交易笔数与方向、是否涉及本公司 |
| **内阁与高级官员** | 财政、商务、贸易、能源、科技/AI 事务负责人等的财务披露与利益冲突报道 |
| **专门机构** | ProPublica 官员披露数据库、CREW 调查报告、OpenSecrets |
| **人事联结** | 本公司或其创始人是否被任命进入政府顾问委员会/科技委员会 |
| **监管互动** | 该届政府对本国反垄断/监管立场的表态，以及对本公司的实际影响 |
| **议会议员** | 国会议员交易记录（**注明这不属于"白宫官员"，仅作补充**） |

### 3.3 报告结构

- **8.1 总统/最高层本人**：披露期 / 已核实内容 / 来源。若涉及本公司，必须写出方向（增持/减持）。
- **8.2 内阁与高级官员**：表——官员 / 已核实的利益冲突 / **是否涉及本公司**。本轮调查的核心结论常常是"**未能核实到任何一名官员持有本公司**"。
- **8.3 与本公司直接相关的"政治-资本"接口**：顾问委员会任职、政策立场、监管互动。
- **8.4 本节结论**：
  - 【已核实】……
  - 【未能核实】……
  - **对投资者的含义**：通常是——**"官员个人账户不构成投资逻辑；真正有意义的政治变量是监管环境，而不是官员的持仓。"**

### 3.4 强制性纪律

- **检索不到就写"未能核实到任何一条"**，不得用"可能持有"、"市场传闻其持有"来填充版面。
- 官员持仓与公司经营的**因果链必须有证据**。仅仅"某官员持有多只科技股"不构成对本公司的结论。
- **区分"个人账户"与"配偶/信托/子女账户"**——申报口径不同。
- 涉及金额时，美国申报文件多用**区间**（如"$1,000,001–$5,000,000"），**不要把它写成精确数字**。
