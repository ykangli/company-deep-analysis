# 估值、情景预测与安全边际方法

本文件定义必须使用的计算方法。`scripts/compute_metrics.py` 实现了其中可自动化的部分；无法自动化的部分按此手工完成。

---

## 一、核心利润的剥离（最重要的一步）

**若报表净利润中包含大额非经营性项目，必须先剥离，否则所有估值指标都是错的。**

常见非经营性项目：
- 非上市/上市股权的**公允价值变动**
- 处置子公司或资产的一次性收益
- 诉讼赔付、罚款
- 大额资产减值
- 政府一次性补贴（A股常见）
- 递延所得税的一次性调整

### 计算方法

```python
# 核心净利 = 报表净利 − 一次性项目税后影响
核心净利 = 报表净利 − Σ(一次性项目税前金额 × (1 − 有效税率))
核心EPS  = 核心净利 ÷ 稀释股本
核心PE   = 现价 ÷ 核心EPS
```

**优先使用公司自己披露的税后影响**（很多公司会在财报脚注中直接写明"该收益使净利增加 X、EPS 增加 Y"）。公司披露的数字优先于你的估算。

### 必须检查的交叉验证

用现金流量表中的**"权益性投资损益"加回项**（non-cash add-back）反查利润表中的其他收入，两者应大致匹配。若差异巨大，说明有其他项目，需要进一步拆分。

### 呈现方式

- 报告 2.6 节给出四列表：期间 / 报表净利 / 一次性项目（税前）/ 税后影响 / 核心净利 / 核心EPS / 报表EPS。
- 若 GAAP PE 与核心 PE 差异 **>30%**，在估值章节显著位置加 ⚠️ 失真警告。
- **在"零、核心结论摘要"的"三个数字"中，把核心 PE 放进去。**

## 二、估值倍数

必备口径与计算方式：

| 指标 | 公式 | 说明 |
|------|------|------|
| 静态 PE | 现价 ÷ 最近一个完整财年 EPS | 用于历史区间对比 |
| PE(TTM) | 现价 ÷ 最近四个季度 EPS 之和 | **若含一次性收益则失真** |
| **核心 PE** | 现价 ÷ TTM 核心 EPS | **估值主口径** |
| 核心静态 PE | 现价 ÷ 最近财年核心 EPS | |
| PS | 总市值 ÷ TTM 营收 | 适合低净利率公司 |
| PB | 总市值 ÷ 最新期末股东权益 | 注意区分"总权益"与"普通股权益"（扣除优先股） |
| EV/EBIT | (市值 − 净现金) ÷ TTM 营业利润 | 剔除资本结构差异，适合同业比较 |
| FCF 收益率 | TTM FCF ÷ 市值 | |
| **股东总回报率** | (最近年度回购 + 股息) ÷ 市值 | **判断"是否靠股东回报就能拿收益"** |

**每股净资产必须说明用的是哪一期**（最新季末/年末），并注意期间是否有大额增发或重估。

## 三、五年估值区间（判断"贵不贵"的关键）

做两张表：

**表一：年度静态 PE 区间**

```markdown
| 年份 | 股价区间（复权后） | 用当年 EPS 的静态 PE |
|------|:---------------:|:-----------------:|
```

**表二：TTM PE 时序**——按"报告期结束后约 30 个交易日（财报已发布）"取当日收盘价 ÷ 该期 TTM EPS。

**结论格式（必须）**："无论用哪种口径，当前都处在近五年估值区间的**上沿/中部/下沿**"，并给出一句对比（如"高于 20XX–20XX 年的全部区间"）。

⚠️ **多类股/复权注意**：若报告期内发生拆股，历史价格必须按拆股比例还原；若用未复权价计算历史 PE，会得出荒谬结果（如 400 倍 PE）。

## 四、内在价值：至少三种方法

### 方法一：盈利 × 合理 PE（最贴近市场定价）

四档情景：悲观 / 保守 / 中性 / 乐观。每档必须写清：
- EPS 假设（用**核心 EPS**，并说明是当年还是次年）
- 给予的 PE 及其依据（历史区间？同业？增速匹配？）
- 隐含股价与相对现价的涨跌幅

### 方法二：DCF

必须写明：**WACC、永续增长率、起始 FCF 口径、显性期年数**。

**若当期 FCF 为负**（重资本投入期），不能直接用当期 FCF 起算。做法：
1. 从"资本开支正常化后"的年份起算；
2. 对稳态 FCF 做**敏感性表**（4 档），每档说明对应的资本开支假设；
3. 显式说明"当前处于资本开支高峰，DCF 的可靠性下降"。

### 方法三：反向 DCF ★ 不可省略

**用现价倒推市场隐含的稳态自由现金流**，再评估该假设是否合理：

```
隐含稳态FCF = 市值 × (WACC − 永续增长率)
```

然后回答：
- 这个 FCF 是当前 FCF 的多少倍？
- 对应需要多高的 FCF 率或多大的营收规模？
- 历史上该公司达到过这个水平吗？
- **结论**：现价是"合理"还是"必须非常成功"？**是否给"增长不及预期"留了缓冲？**

### 方法四（如适用）：行业专用回收指标

对重资本投入的公司，定义一个"投入产出比"，给出刻度与当前位置。范例（算力基建）：

```
回收率 = 近12个月分部经营利润 ÷ 近12个月资本开支
```

刻度示例：15% = 模式初步成立；25% = 买入逻辑被验证；30% = 需要重新估值。

**明确指出当前读数落在哪一档。**

## 五、三种情景预测（第十章的骨架）

| 行 | 内容 |
|----|------|
| 概率 | 三档相加 = 100% |
| 核心假设 | 每档 3–4 条，可证伪 |
| 逐年营收 | 至少到 3 年后 + 5 年后 |
| 逐年核心 EPS | 同上 |
| 资本开支路径 | 重资本公司必填 |
| 稳态 FCF | DCF 的输入 |
| 合理 PE 区间 | 与情景匹配（悲观给低倍数） |
| 目标股价 | 稳态 EPS × 合理 PE |
| **年化回报** | 含股息，从现价算起 |

表后必须给出**概率加权预期年化回报**，并与该公司过去 5 年的实际年化回报对比，解释差异（通常是因为估值起点变高）。

## 六、安全边际评分（第十一章）

九个固定维度，各 0–10 分：

| 维度 | 评分依据 |
|------|---------|
| 商业模式与护城河 | 四类护城河的强度与可持续性 |
| 财务健康度 | 净现金、负债率、现金流覆盖 |
| **盈利质量** | 报表利润与核心利润的偏离程度；OCF/净利 |
| 成长性 | 收入与利润增速、新业务占比 |
| 管理层质量 | 坦诚度、战略执行力 |
| 资本配置 | 回购/研发/并购/分红的实际效果 |
| 估值水平 | 核心 PE 在历史区间的分位 |
| **价格安全边际** | 内在价值 vs 现价；与"聪明钱成本锚"的比对 |
| 行业周期位置 | 处于周期的哪个阶段 |
| **综合** | 加权，并写出与前次评估的对比（如有） |

**"价格安全边际"与"综合"两行的分数必须与第零章一致。**

## 七、价格纪律表（第十二章，必须给出）

```markdown
| 价格区间 | 对应 {核心PE/其他口径} | 判断 | 建议动作 |
|---------|:--------------------:|------|---------|
| > $X | > xx 倍 | 明显高估 | 减持/不买 |
| $A–$B | … | 偏高 | 持有，不加仓 |
| $C–$D | … | **公道价格（当前区间）** | 可分批建仓（首笔 ≤ 1/3） |
| $E–$F | … | 有吸引力 | 加速建仓 |
| $G–$H | … | **明显低估** | 重点加仓 |
| < $I | < xx 倍 | 极度低估（需确认非基本面恶化） | 视基本面定性 |
```

配套必须给出：
1. **仓位上限建议**与理由
2. **分批方案**（几批、各在什么价位）
3. **必须跟踪的 3–4 个变量**（具体到指标名）
4. **触发"重新评估"而非"机械补仓"的信号**（例如"分部增速连续两季低于 X%"）

## 八、常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 用 GAAP PE 做估值锚 | 严重低估真实估值 | 先剥离一次性收益 |
| DCF 用当期 FCF 起算（当期含巨额资本开支） | 得出荒谬的低估值 | 从资本开支正常化后起算，并做敏感度 |
| 只给一个 DCF 数字 | 无法判断假设敏感性 | 至少 4 档敏感度 |
| 不做反向 DCF | 不知道价格里已经装了什么 | 必须做 |
| 用 TTM 数据跨财年直接比较 | 季节性误导 | 同比对比或 TTM vs TTM |
| 同业比较不换货币 | 数量级错误 | 统一货币并注明汇率日 |
| 情景概率不合理（如乐观 60%） | 加权回报虚高 | 悲观+中性应占多数 |
