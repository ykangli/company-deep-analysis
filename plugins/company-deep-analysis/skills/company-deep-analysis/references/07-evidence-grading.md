# 证据分级与标题陷阱清单

本文件是报告可信度的最终防线。写作与交付前各读一遍。

---

## 一、三档标记（唯一允许的标记体系）

| 标记 | 含义 | 使用条件 |
|------|------|---------|
| `【已核实】` | 从一手法定披露（L1）或官方数据接口（L2）读到 | 能给出文件名/接口名 + 日期 |
| `【推算】` | 你基于已核实的输入，按明确公式推导 | **必须inline写出公式与假设** |
| `【未能核实】` | 已检索但未找到 | **必须说明检索了哪几类来源** |
| `【二手转述】` | 仅有媒体报道/搜索摘要支撑 | 只能作为线索，不得作为承重结论 |

**不允许的表述**：`可能`、`据传`、`市场普遍认为`、`有分析指出`（无具名）、`大约`（无公式）。
出现这些词，要么补来源升级为 `【二手转述】`，要么改为 `【未能核实】`。

---

## 二、承重结论的定义

**承重结论** = 出现在下列任一位置的判断：
- 第零章"一句话结论"与"三个数字"
- 第十二章"结论"与"价格纪律表"
- 第十一章评分表中任一维度的打分依据
- 第九章（检查清单）任一题的答案
- 第三章任一估值结论

**规则：承重结论中出现的每个数字，必须是 L1 或 L2。**

## 三、推断 vs 事实的边界（最重要的一节）

以下对照表来自真实事故。**左列是"看起来像事实的推断"，右列是"可写进报告的表述"。**

| ❌ 不可写 | ✅ 应写成 |
|----------|---------|
| "商誉增加 244 亿，系完成 Wiz 收购所致" | "完成一笔大型收购（商誉 X→Y，收购现金支出 Z）；**标的名称未能核实**（一手文件中未出现相关名称）" |
| "巴菲特卖出 Alphabet" | "某子公司（独立申报主体）减持 Alphabet X%；**母公司同期增持 Y%**" |
| "管理层买入本公司股票" | "管理层获得股权激励授予（$0.00/股）；**本期无公开市场买入**" |
| "李录的持仓成本是 $87" | "李录持仓成本**未能核实**；按其已披露的交易时点季末价推算，加权均价约 $87.5【推算】" |
| "该季度机构大举加仓" | "已核实的加仓方：A（+X 万股）、B（+Y 万股）；**另有 C 减持 45%、D 清仓**" |
| "市场预期增长 20%" | "N 家机构一致预期为 X%（来源、日期）" |

### 判定方法（三条自问）

1. **这个因果推断，在一手文件里有直接表述吗？** 没有 → 不能写成事实。
2. **如果把主语换成另一家类似公司，这句话还成立吗？** 成立 → 说明它是常识推断，不是本公司的核实事实。
3. **搜索引擎的标题与摘要，是否等于正文？** **不等于。** 标题经常是编辑的概括，可能与正文口径相反。

**执行动作**：对任何来自 subagent / 媒体 / 搜索摘要的承重结论，**回到已下载的一手文件做一次全文检索确认**：

```bash
grep -n "关键词" ./work/primary/*.txt
```

## 四、标题陷阱清单（已知的高频错误）

| # | 陷阱 | 真相 | 处理 |
|:-:|------|------|------|
| 1 | "某投资大佬卖出 X" | 常为其子公司/关联机构的**独立申报** | 先确认申报主体 CIK |
| 2 | "大佬买入 X 亿" | 多为**季末市值**，非实际投入 | 注明口径 |
| 3 | "某基金清仓 X" | 13F 只覆盖美股多头；**不代表无相关敞口** | 加限定语 |
| 4 | "某名人做空 X（买 put）" | 需核对其**最后一期 13F**；且期权按名义价值申报 | 核对申报；若已注销注册则说明"无披露义务" |
| 5 | "公司回购彰显信心" | 需检查**股本是否真的减少**（可能被 SBC/增发抵消） | 给出稀释股本逐年变化 |
| 6 | "PE 只有 17 倍，很便宜" | 分母可能含一次性收益 | 算核心 PE |
| 7 | "分部收入 1,680 亿"（与总量级不符） | 常是**积压订单/合同额**被写成季度收入 | 量级校验；弃用 |
| 8 | "市值突破 X 万亿" | 中文媒体常有日期与来源缺失的夸大标题 | 用行情接口实测 |
| 9 | "某官员持有 X 公司" | 常是"持有科技股若干只"被概括成具名公司 | 回到披露原文 |
| 10 | "完成 X 公司收购" | 一手文件可能未点名 | 反查后写"未能核实" |
| 11 | "内部人增持" | 价格字段 $0.00 的是**激励授予** | 与买入严格分开 |
| 12 | "创始人减持 X 亿" | 可能是**赠与（gift）** | 区分赠与与卖出 |

## 五、必须写进报告的两份清单

### 1. 未能核实清单

集中列在"数据来源与时效性说明"中，每条格式：

```
- {项目}：未能核实（已检索 {来源A}、{来源B}、{来源C}）
```

### 2. 已剔除 / 已纠正的数据清单

**这是诚实性的体现，不是丢脸。** 格式：

```
- {数据}（{来源}）：{剔除原因，如"口径与季度收入量级不符，疑为积压订单口径"}
- {推断}：原写作"{错误表述}"，经检索一手文件未发现相关表述，已改为"{正确表述}"
```
